Qanday o‘rnatiladi?

Quyidagi qadamlar qurilmangizga mos. O‘rnatilgan veb-ilova alohida oynada ochiladi.

iPhone / iPad

Safari orqali

  1. Ushbu sahifani Safari brauzerida oching.
  2. Quyidagi ServicePro’ni ochish tugmasini bosing.
  3. Safari menyusida Ulashish (Share) tugmasini bosing.
  4. Bosh ekranga qo‘shish (Add to Home Screen)ni tanlang.
  5. Web App sifatida ochish yoqilganini tekshiring va Add bosing.
macOS 14+ (Sonoma va keyingi)

Mac uchun

  1. Ushbu saytni Safarida oching.
  2. ServicePro’ni ochish tugmasini bosing.
  3. Safari’dagi File → Add to Dockni tanlang.
  4. Nomini ServicePro qilib tasdiqlang.
  5. Endi ilovani Dock yoki Applications’dan ochasiz.
Android

Chrome orqali

  1. Saytni Chrome’da oching.
  2. Yuqorida Ilovani o‘rnatish tugmasi chiqsa, bosing.
  3. Aks holda Chrome menyusidan Install app yoki Add to Home screenni tanlang.
Windows / boshqa kompyuter

Edge yoki Chrome

  1. Saytni Edge yoki Chrome’da oching.
  2. Brauzer menyusidan Apps → Install this site as an appni tanlang.
  3. Yoki Windows uchun Microsoft Store ilovasini o‘rnating.

Eslatma: Bu App Store’dagi .ipa emas, o‘rnatiladigan veb-ilova (PWA). Ishlashi uchun internet va saytning HTTPS manzili kerak. Brauzerda kamera/video va push-bildirishnomalar imkoniyatlari platformaga qarab farq qilishi mumkin.
